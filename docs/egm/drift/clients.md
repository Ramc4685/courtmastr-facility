## backend/app/modules/clients/README.md

Re-checked 2026-11-13 against the working tree. The ten items of the earlier report (README lines 27-45 then) are fixed in the README and are not repeated.

- [stale-not-built] README:48 lists CSV export (`createClientExport`) as not built. The clients context has no such route, but a CSV-oriented client export exists as the `client_export` report in reporting (`backend/app/modules/reporting/reports/clients.py:170-176` params and builder, `:448-454` registration), and `docs/api/openapi-people.yaml:1969` still carries the operation. The README should say it is served by reporting, or the openapi operation should be marked as moved.
- [stale-not-built] README:49-50 says the booking clause of the `own` reach predicate "waits for scheduling". Scheduling is built; the clause is still absent (`backend/app/modules/clients/service.py:79-85`, `_own_clause` checks only default trainer and salesperson), and its docstring still says scheduling "is not built yet" (`service.py:81`). The blocker text is stale, the gap is real.
- [undocumented] README:7-15 (file table) omits `terms.py` (`backend/app/modules/clients/terms.py:1-28`, `register` and `acknowledge`), which `__init__.py:8-10` exports. It appears only in the Phase 11 section at README:117-118.
- [undocumented] README:44 says an imported client's `clients.client.created` event carries `source: "import"`. The event also takes `source: "guest"` for guest checkout (`backend/app/modules/clients/events.py:14-16`, set at `service.py:800` from `created_via == "registration"`). README:115-116 describes `create_self_service` but not this.
- [undocumented] README:35 mentions only the client-ids resolver registered with platform. `__init__.py:16-19` also registers `service.activate_access_for_identity` as an activation hook (`platform.auth.ACTIVATION_HOOKS`) and `service.count_active_clients` as the PLT-14 `clients` usage counter. Neither is in the README.
- [contract] README:117-118 describes `clients.terms` as a registry that sale paths call. `terms.acknowledge` uses `assert _recorder is not None` (`terms.py:26`), so under `python -O` a missing recorder becomes a `TypeError`, and clients does not guarantee that `documents` is imported (registration at `documents/service.py:1278`). The README does not state that documents must be imported first.
- [wording] README:115 gives `created_via=portal|registration`. `create_self_service` accepts any string, and anything other than `portal` is treated as `registration` (`backend/app/modules/clients/service.py:1182,1187`); nothing validates it.
