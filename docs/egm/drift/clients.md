## backend/app/modules/clients/README.md

- [contract] Member number: the contract has `PUT /clients/{client_id}/member-number` (`docs/api/openapi-people.yaml:428`), the router serves `POST` (`backend/app/modules/clients/router.py:101`). README names neither.
- [contract] Path parameter names differ for the lookup routes: the contract uses `{id}` (`openapi-people.yaml:523,606,670`), the router `{client_category_id}`, `{referral_category_id}`, `{note_subject_id}` (`router.py:133,139,156,162,396,403`). A generated client for the contract path does not match the served path template.
- [contract] `updateClientLocationSettings` is `PATCH /client-location-settings/{location_id}` in the contract (`openapi-people.yaml:904`) and `PUT` in the router (`router.py:226`).
- [contract] README:87-88 names `getClientNoteAttachment` as an always-download route. The contract's `getClientNoteAttachment` is `GET /client-notes/{note_id}/attachment` returning a signed URL (`openapi-people.yaml:1761-1766`). The router serves `GET /client-notes/{note_id}/attachments/{attachment_id}` (bytes), plus list, upload and delete routes (`router.py:535-554`) that the contract lacks.
- [contract] Served routes with no contract operation and no README mention: `GET /clients/{client_id}/photo` (`router.py:530`; the contract has only `setClientPhoto` PUT at `openapi-people.yaml:292`; README:87 names `getClientPhoto`), `GET /clients/{client_id}/timeline` (`router.py:468`) and `POST /public/email-verifications/confirm` (`router.py:373`).
- [undocumented] README:7-15 (file table) omits `terms.py` (`backend/app/modules/clients/terms.py:1-28`), exported by `__init__.py`. It appears only in the last section (README:117-118).
- [undocumented] README:19-24 (internal interface) omits `service.create_self_service` (`service.py:1178`) and `terms.acknowledge` (`terms.py:21`), which other contexts call; they appear only at README:113-118.
- [undocumented] README:43-44 says an imported client's `clients.client.created` event carries `source: "import"`. The event also sets `source: "guest"` for a client made by guest checkout (`backend/app/modules/clients/events.py:12`; `service.py:796`, `{"import": "import", "registration": "guest"}`), and automations skip it.
- [undocumented] `clients.client.export` is registered (`backend/app/modules/clients/permissions.py:29`, flag `X`, admin) but no route or service function checks it. README:47-48 lists CSV export (`createClientExport`, `openapi-people.yaml:1967`) as not built but not the unused key.
- [wording] README:49-50 says the booking clause of the `own` reach predicate "waits for scheduling". Scheduling is built and the clause is still absent (`service.py:77-83`, docstring "needs scheduling, which is not built yet"). The stated reason is stale.
- [wording] README:115 gives `created_via=portal|registration`. `create_self_service` takes any string and treats everything other than `portal` as `registration` for the context, while storing the raw value (`service.py:1178-1183`).
