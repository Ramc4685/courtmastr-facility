# cookies became one `__Host-fh_session` cookie, browser sign-in needs the `__Host-fh_pre` cookie from

# OpenAPI document has no cookie or header parameters for it, and the diff against the merge base with main is
# four added endpoints plus three description edits (no breaking entry). So S1 needs no line here; the contract
# change is recorded in docs/status/phase8-s1-signin.md and docs/dev/checks.md ("What the diff cannot see").
