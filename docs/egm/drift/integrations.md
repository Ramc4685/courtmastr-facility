- [contract] README 75; `schemas.py:128-143`, `router.py:149-156`. - [contract] README 74 (`provider-not-configured`), 179-181 (`409 already-exists`); `schemas.py:117-127`, `service.py:673-676`, `models.py:138`. `createExternalConnection` (6866) lists `connection-exists` and `provider-not-available`. - [undocumented] README 165-166 ("due tokens are refreshed under a row lock"); `quickbooks.py:83-97`. `credentials()` locks and reloads the row on every call, not only when a refresh is due, so mapping reads and every posting hold the lock. `refresh_if_due` (`:106`) and `get_mappings` (`:270`) catch bare `Exception`, which would also swallow a database error.
- [undocumented] README 77-79 (a POST callback because a mutating GET is not allowed); `quickbooks.py:83-97, 257-275`. `GET .../sync-mappings` can refresh and reseal credentials, so this GET writes to the row and locks it.
- [undocumented] README 163-166; `quickbooks.py:303-344, 391-428`. - [undocumented] README 167-169 (stale takeover); `quickbooks.py:354-362, 376-388, 431-436`, `jobs.py:34-36`. A takeover is audited only as `integrations.sync.start`. `GET .../sync` is gated by `integrations.sync.run` (`router.py:210-214`) and shows an `idle` status; the README says neither.
- [undocumented] README 180-181 (a pending or errored row is taken over); `service.py:665-696`, `quickbooks.py:165-173`. - [wording] README 69 (`FH-<LOCATION SLUG>-<YYYYMMDD>`); `service.py:804`. The slug is upper-cased and cut to 12 characters, so two locations that share a 12-character prefix get the same doc number for the same day.
