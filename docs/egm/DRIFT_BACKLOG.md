# Drift backlog

Every place a module README and the code disagree, found 2026-11-12 by EGM drift reports (fresh "goldfish"
reviewers, read-only, no tests run). 178 items across 19 module READMEs. Ticked items name their fix commit (`TRIAGE.md`, fix log).
Per-module evidence with file:line lives in `drift/<module>.md`; the checklist below is the same content.

Tags: `[stale-not-built]` doc says missing, code has it · `[missing]` doc says built, code lacks it ·
`[contract]` API, permission or event mismatch · `[undocumented]` code exists, doc silent · `[wording]`.
Resources and assessments were checked before tags existed, so their items are untagged.

A commit-time hook in `.claude/settings.json` (`.claude/hooks/egm-drift-gate.sh`) stops an agent's
`git commit` until each module it changed has a fresh report, so new drift lands here instead of piling up.
