### API keys and the contract's security model (new)

- [contract] The contract marks 28 integrations operations as callable with an API key (`security: [{staffSession: []}, {apiKey: []}]`): the four `/api-keys` operations (openapi-programs.yaml:6375, 6403, 6424, 6442), `listWebhookEventTypes`, the seven webhook-endpoint operations, the three delivery operations, and the 13 connection, mapping, export, sync, adapter and adapter-command operations (6456 through 7039).
