## backend/app/modules/integrations/README.md

- [wording] Line 17 says `jobs.py` has "an unscheduled sweep", but line 64 says `sweep_webhook_deliveries` runs every minute. The scheduler does enqueue it (`backend/app/scheduler.py:20`, `EVERY_MINUTE`), so line 17 is stale. The actor's docstring makes the same stale claim: "nothing schedules this yet" (`backend/app/modules/integrations/jobs.py:21-22`).
- [contract] Line 18 says `router.py` holds "the endpoints in `docs/api/openapi-programs.yaml` tag integrations". It serves 22 of the 40 operations the contract lists for the module (`backend/app/modules/integrations/router.py:30-175`). One of the 22 differs in path: contract `listAccountingExports` is GET `/external-connections/{connection_id}/accounting-exports`, but the code serves GET `/accounting-exports` with an `external_connection_id` filter (`router.py:152-155`). The code's `external_connection_id` path parameter on disconnect (`router.py:145`) also differs from the contract's `connection_id`.
- [undocumented] Contract operations that aren't served and aren't in the "Not built" list (lines 67-69): `getExternalConnection` (GET `/external-connections/{connection_id}`), `updateExternalConnection` (PATCH, same path), `runSync` (POST `/external-connections/{connection_id}/sync`), `retryAccountingExport` (POST `/accounting-exports/{accounting_export_id}/retry`), `receiveQuickBooksEvents` (POST `/webhooks/quickbooks`) and `receiveZoomEvents` (POST `/webhooks/zoom`). All are in `docs/api/openapi-programs.yaml`; none is in `backend/app/modules/integrations/router.py`. "Not built" does cover the calendar feeds, the session video meeting operations, sync mappings and the OAuth callback.
- [wording] Lines 49-50 say `integrations.webhook_allow_localhost` is "dev only ... startup refuses it elsewhere". Startup refuses it only outside dev and test (`backend/app/core/settings.py:283-284`), so test may enable it too.
- [undocumented] `permissions.py` (not in the file table) registers `integrations.calendar_feed.revoke_any` (`backend/app/modules/integrations/permissions.py:19`), a key for the calendar feed that line 69 lists as not built. The README never names the module's other keys (`api_key.manage`, `webhook.manage`, `connection.manage`, `sync.run`, `delivery.read`; `permissions.py:14-18`), or the `+` step-up flag on `api_key.manage` (`:14`).
- [undocumented] `events.py` is not in the file table (`backend/app/modules/integrations/events.py:9-15`). Line 47 mentions `integrations.webhook_endpoint.disabled`, but not that it carries a `reason` and is never delivered to webhooks (`webhook = false`).
