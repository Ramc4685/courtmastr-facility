## backend/app/modules/imports/README.md

- [contract] README lines 36-50 describe the routes `PUT /import-jobs/{id}/source`, `POST /import-jobs/{id}/dry-runs`, `POST /import-jobs/{id}/commits` and `GET /import-jobs/{id}/error-report`. The router implements exactly those (backend/app/modules/imports/router.py:63-96), but the API contract docs/api/openapi-core.yaml does not. It declares `POST /import-jobs/{import_job_id}/commit` (singular, operationId `commitImportJob`, openapi-core.yaml:1559), `GET /import-jobs/{import_job_id}/rows` (`listImportJobRows`, :1544) and `POST /import-jobs/{import_job_id}/cancel` (`cancelImportJob`, :1574), and has no source, dry-runs or error-report paths. The router's operation ids (camel_id: `createImportJobCommit`, `uploadImportJobSource`, ...) therefore do not match the contract's operationIds.
- [contract] README line 172 lists "cancelling a running job" as deferred, which matches the code (no cancel route in router.py; `service.py` has no cancel function). The API contract still publishes `cancelImportJob` (docs/api/openapi-core.yaml:1574) as if it were built.
- [undocumented] The Flow section (README lines 36-50) leaves out three routes: `GET /import-templates` (template listing with each type's fields, help and guide, router.py:44-46 / service.py:75-77), `GET /import-templates/{kind}` (header-plus-example CSV, router.py:49-52 / service.py:80-84) and `GET /import-jobs` (list with `kind`/`status` filters and `created_at` sort, router.py:54-56 / service.py:242-250). Line 165 mentions "the downloaded template" but never says where it comes from.
- [undocumented] The commit refuses a job with no importable rows: 409 `nothing-to-import` (service.py:227-228). Flow step 4 (README lines 45-47) names only `check-stale`.
- [undocumented] Upload validation is not in the README: accepted content types `text/csv`, `application/csv`, `text/plain`, `application/vnd.ms-excel` (service.py:51, 174-175), and error codes `file-empty`, `file-too-large`, `file-type-mismatch`, `file-not-utf8`, `file-not-csv`, `file-no-header`, `file-duplicate-header`, `file-too-many-rows`, `file-infected` (router.py:65-67). Also missing: an upload after the check has started is 409 (service.py:168-169), and a dry run on a `new` job is 409 "Upload a file first" (service.py:199-200).
- [undocumented] A row that hits a database IntegrityError is `failed`/`invalid` with code `already-exists` (service.py:321-325). README line 58-59 describes only refusals and `unexpected`.
- [wording] README line 113 says the commit hits `entitlements.enforce_limit` "inside `clients._create`". The function is `clients.service._create` (backend/app/modules/clients/service.py:756, call at :769).
