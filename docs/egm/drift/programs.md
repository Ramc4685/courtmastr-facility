- [wording] The README (`README.md:56-58`) says a live link waives "the hidden, list-only, visible-range and self-bookable checks". The code matches: `linked` skips `list_only` and `not-self-bookable` in `_verdict` (`selfservice.py:146-149`) and `hidden` and `beyond` in `_bookable_seat` (`selfservice.py:204-207`). But the README says the link "books an unlisted session", while an `unlisted` session needs no link: `_bookable_seat` blocks only `hidden` (line 204, comment "unlisted stays bookable by direct link"), and `_verdict` has no `unlisted` check. Any signed-in client who knows the session id can book an unlisted session without a token. The README does not say so, and nothing enforces "bookable by link only".
